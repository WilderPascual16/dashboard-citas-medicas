# Dashboard de Gestión de Citas Médicas

## Descripción
Proyecto académico de Business Intelligence
para analizar las citas médicas de un hospital
de Lima Norte.

## Herramientas
- Python
- Pandas
- NumPy
- Scikit-Learn
- Plotly
- Streamlit

## Funcionalidades
- Análisis de citas por especialidad.
- Porcentaje de citas atendidas y canceladas.
- Análisis de ausencias.
- Tendencia mensual de citas.
- Visualización de registros médicos.

## Dataset
El proyecto utiliza un conjunto de datos
simulado de 5000 registros.
